## Jak dodać siebie

1. Zrób fork i utwórz branch (`git checkout -b feature/nazwa`).
2. Zmień kod lub dokumentację.
3. Sprawdź składnię: `node --check wtyczka/content.js` oraz `python3 build_userscript.py`.
4. Otwórz Pull Request z krótkim opisem zmiany.

Commity z współautorem podpisujemy w stopce:

```
Co-authored-by: Imię Nazwisko <email@example.com>
```

Dzięki temu GitHub pokazuje tę osobę na liście współtwórców repozytorium.
